# AVTool

面向个人使用的视频目录、筛选、播放与缓存工具。

默认普通模式，仅接入用户自行填写的 **Bilibili、抖音**链接。提供本机网页、目录导入、热门筛选、播放和可选的云盘缓存；不附带片库、账号或云盘授权。

## 快速启动

- **Windows：** 安装 Python 3.10+（推荐 3.12）和 Node.js 22.12+（推荐 24 LTS），解压源码包后双击 `start-windows.bat`。
- **Ubuntu：** 安装 `python3 python3-venv ffmpeg rclone` 及 Node.js 22.12+，解压源码包后执行 `./start-ubuntu.sh`。
- 打开 `http://127.0.0.1:8787`，点“导入链接”加入自己有权使用的视频。Ctrl+C 停止服务。

Git 仓库和源码包均不包含构建产物。首次启动需要网络安装 Python、前端依赖，并使用 Node.js 22.12+ 在本机构建网页；后续启动复用本机构建结果。分离音视频播放需要 FFmpeg；云盘缓存还需 rclone 及用户自己的独立授权，默认关闭。

完整步骤见 [安装与使用](DEPLOYMENT.md)。让 AI agent 部署时，先让它阅读 [AGENT_DEPLOYMENT.md](AGENT_DEPLOYMENT.md)。包内附 `FILE-SHA256.json` 文件校验清单，外部 `SHA256SUMS.txt` 用于校验压缩包。

## 功能范围

- 视频目录浏览、搜索、标签筛选和热门排序。
- 源站播放与手动缓存，支持缓存队列、进度查看及任务取消。
- 配置用户自己的存储后保存视频；公开版本不得携带作者的云盘账号或授权。

公开版本的默认普通模式以 **Bilibili 和抖音**为支持范围，仅面向用户有权访问、下载和保存的内容。能在浏览器中观看，不当然代表有下载、转载或再分发授权。平台接口、账号权限与内容可用性可能变化，不保证任意链接均可解析或播放。

新安装默认启用普通模式。特殊模式采用显式配置的本地 Python 适配器接口，参考 `special_plugin.example.py`；不内置或自动下载内容来源。既有私人实例无需因本发布包改变模式，但其内容来源、数据与账号配置不属于公开发布内容。
